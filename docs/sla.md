# Support SLA (Tier 14) — beta terms

## SLA sokongan (term beta)

- **Response:** < 24h on business days via reply to any Themis email.
  **Respons:** < 24 jam hari bekerja melalui balasan mana-mana e-mel Themis.
- **Uptime target:** 99% monthly on the single Render instance (see footer
  status dot, backed by `/api/health`). Public status page at scale.
  **Sasaran:** 99% bulanan.
- **Data:** claims content never stored server-side; leads retained per
  `docs/owner-checklist.md` retention notes.
  **Data:** kandungan tuntutan tidak disimpan di pelayan.
- **Security contact:** reply to any beta email with subject `SECURITY`.
  **Keselamatan:** balas e-mel beta dengan subjek `SECURITY`.
- **Outages:** status banner in-app + owner mail; postmortem filed in repo.
  **Gangguan:** sepanduk status + postmortem dalam repo.
